# 0.1.0 模拟原型架构

> 2026-10-29：用户授权开始功能开发，先打通界面、内核和模拟设备。这里记录实现决策，不表示真实芯片协议已确认。

## 1. 当前范围

- Electron 桌面外壳与普通浏览器使用同一套 Vue 界面。
- Python 内核管理多个模拟设备会话、寄存器和单硬件任务；SQLite 保存连接配置和日志。
- PySerial 当前仅用于枚举系统串口，未调用串口连接/读写；PyVISA、真实芯片寄存器和厂商脚本未接入。串口扫描不表示真实驱动或设备通信已完成。
- SoC 的 `transport` 为 `serial`，仪表为 `tcpip`；`mode` 独立表示 `simulation` / `hardware`。真实驱动尚未接入，硬件模式只允许保存有效参数，不建立会话；仪表模拟会话不包含虚构 SCPI 测试结果。

## 2. 目录职责

| 路径 | 职责 |

| `frontend/src/components/` | 独立位编辑器与日志视图 |
| `backend/service.py` | 统一连接会话、访问策略、单任务调度；不导入 FastAPI/GUI |

| `tests/` | Python 服务/API 测试、浏览器交互及主题验证 |

## 3. 生命周期和接口

1. 启动器在本机为 Python 内核分配空闲端口，传入随机会话凭据。
2. Python 创建独立数据库、加载配置，但不自动连接设备，输出就绪端口。
3. 启动器健康检查通过后，Electron 打开内核上的已构建前端；开发模式由 Vite 代理。
4. 界面通过 `POST /api/bootstrap` 建立同源 HttpOnly/SameSite 会话，再通过 `/api/events` WebSocket 获取状态快照。
5. 连接和任务发生变化时递增版本号，推送快照；重连重新获取权威状态。
6. 关闭桌面先确认运行中任务，再通过标准输入请求退出，内核停止任务并释放会话；父进程管道关闭也触发清理。

HTTP 和 WebSocket 检查本机 Host、Origin 和会话，浏览器来源只允许当前来源及受控开发来源。它是本机原型安全边界，不是防御本机恶意软件的沙箱。桌面关闭 Node integration，启用 context isolation 和 sandbox，不允许任意新窗口或外部导航。

主要接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/health`、`POST /api/bootstrap` | 启动检查及界面会话 |
| `GET /api/state`、`WS /api/events` | 状态查询及更新 |
| `POST /api/connections` | 创建模拟配置 |
| `POST /api/connections/{id}/connect`、`disconnect` | 连接/断开 |
| `DELETE /api/connections/{id}` | 删除已断开的配置 |
| `PUT /api/connections/{id}` | 修改已断开的连接参数，保持逻辑设备 ID |
| `GET /api/serial/ports` | 只枚举系统串口号与描述，不打开端口，受本机会话保护 |
| `GET /api/registers/definitions` | 位域定义 |
| `POST /api/registers/preview?filename=...` | 限 8 MB 原始文件体，解析后只预览，不更改目录 |
| `POST /api/registers/sheets` | 只识别 Excel sheet 及 v1/v2/simple 格式，随后用 sheets 参数预览所选表 |

| `POST /api/connections/{id}/registers/write` | 带值、掩码的显式写入与校验 |
| `POST /api/tasks/scan`、`cancel` | 内核模拟回归样例与协作停止；巡检已移除用户界面入口 |

## 4. 寄存器与任务

- 32 位数据按无符号数处理；位域明确 `msb`/`lsb`、RW/RO/WO/WC/Reserved/W1C/W1_PULSE/WC_INT。用户已明确 WC/W1_PULSE/WC_INT 写语义等价，保留原名，统一显式写入。
- 未定义地址拒绝访问，定义必须覆盖全部位，未知位不默认可写。
- 内核初始化仅在目录不存在时种入示例定义；每次导入/删除原子保存带版本号的完整目录，删空后持久化空表，不再自动种入。
- 导入先预览，默认追加且拒绝地址冲突；替换需显式选择。服务端完整校验再持久化，目录版本过期返回冲突，不部分覆盖。
- 模拟连接按当前目录初始化，新增模拟地址建立定义初值，目录修改不调用驱动写操作，也不重置已有地址值。
- 状态事件含目录版本号，前端发现变化后获取新定义，清除原待写缓存并更新选择/详情；所有页面共用同一目录。当前不支持多个独立芯片目录或共享地址定义。
- 界面分别保存读回值、待写值、改动掩码和校验状态；点击 bit 不发写命令。
- 内核校验掩码，不允许整字输入、脚本或 API 绕过只读/保留位；普通 RW 合并修改位，W1C 显式写 1 清零。
- WO 按完整字段显式写入，服务拒绝不完整 WO 掩码；未提交 WO 位取 0，不通过读改写保留或重放旧命令。纯 WO/Reserved 寄存器的单行读取被拒绝，全部读取及巡检跳过，纯只写目录不能启动巡检。模拟驱动也拒绝纯只写读取。
- `readable_mask` 标识有效读回位：混合 WO 位从数值中屏蔽，纯只写掩码为 0。UI 中混合值的相应十六进制位显示 `?`；纯只写的 actual 为 null，待写值从 0 开始。任务读取结果也携带掩码，避免显示虚构的 WO 读回值。
- WC/W1_PULSE/WC_INT 按用户说明为写 1 后硬件自动清 0，显式命令提交，默认待写 0；从读回值合并写入时先清除全部三类自清零位，只置入本次明确提交的 1。模拟驱动在 write 中模拟立即自清零，真实完成时序待硬件驱动定义。
- 写接口返回 `verification_mask`（本次 RW/W1C 位）、`unverified_mask`（本次 WO/WC 位）以及 true/false/null 的 verified。没有可校验位时为 null，不冒充校验成功；混合写入仅比较有效位，WO/WC 状态以文字单独提示。纯只写返回 previous/value/expected 为 null，不调用驱动 read。
- 界面 WO 字段编辑后按完整字段置待写掩码，支持显式零值和重复命令；撤销独立清除掩码。每次读取或写入应答后 WO/WC/W1C 待写位归 0，WC 不根据读回值自动重发。
- 原型模拟驱动支持上述语义。真实设备的自清零、写触发、读清零及动态状态需要单独适配，不能直接套用模拟校验。
- 全局同一时刻一个硬件任务。巡检运行中禁止手动寄存器读写，禁止断开其使用的设备，其他设备可保持连接。
- 任务执行移到工作线程，通过 Event 协作停止，切换/关闭模块标签不停止任务。日志和任务结果留在内核，不依赖页面生命周期。
- 用户认为模拟巡检无实际价值且占据工具栏，已移除寄存器页启动按钮、前端 startScan 方法及关于/任务空状态中的启动引导；内核样例与 API 仅保留为自动化回归负载，验证单任务锁、停止及连接保持。任务中心和通用停止不删除，不将该样例当作真实芯片检查能力。

## 5. 工作区与可读性

- 当前每种模块一个标签，重复打开激活现有标签；关闭最后一个标签返回连接中心。
- 连接卡片按逻辑设备 ID 管理请求锁和“连接中/断开中”反馈；创建配置另有独立锁，不能通过全局 busy 让其他卡片按钮闪烁。内核寄存器任务的全局单任务约束保持不变。
- 不同设备请求可以并发，前端拒绝同一内核实例中 revision 更低的状态快照，避免较慢的旧请求覆盖已接收的最新连接状态。
- 关闭标签不关闭连接或停止任务；底部始终保留运行任务入口，桌面退出需要确认。
- 主导航右边线使用窄悬停区域，移入后在鼠标所在高度显示向左箭头，点击完全收起；收起后命中区移到窗口左边缘，悬停显示向右箭头，点击展开。移除顶部按钮，箭头默认隐藏，鼠标离开隐藏；键盘聚焦时仍显示，支持 Enter/空格。按钮位置跟随 224/208/60 px 的响应式侧栏宽度，不另占工作区，层级低于弹窗。偏好与主题按 Web 来源保存到 localStorage，刷新保持；Electron 使用动态端口，跨桌面启动的偏好持久化后续需改为稳定的应用设置存储。
- 根据用户反馈，主要正文/按钮约 14 px，寄存器与日志约 13 px，bit 值至少 14 px、位号至少 12 px；不因只读状态降低文本透明度。
- 明暗主题的主要文字颜色对面板背景按至少 4.5:1 验证；状态仍有文字说明，不只依赖颜色。
- 位表保持可读，按用户反馈取消所有横向滚动及滑块。寄存器分组用带数量的列表下拉选择；32 位用等宽弹性单元格完整显示，同一行不换行、不拆成 16+16。窄屏时位域详情移到表格下方，不隐藏全部详情。
- 大表（超过 40 项）使用可见行渲染：容器宽度至少 1120 px 时每行 112 px，名称/数值/32 位/操作并排；更窄时每行 144 px，上排名称/数值/操作，下排完整 32 位。行高变化时保持当前行位置，前后空白占位行同步更新。表格容器只纵向滚动，thead 吸顶，上下各预留 5 行。40 项以内直接渲染，不引入新依赖。行状态由 store 按设备/地址持有，离屏回收不清除待写值，当前筛选全选覆盖全部匹配定义。
- 每行拆为独立组件，bit31～bit0 的字段、颜色、权限和提示按定义预计算，修改一行时不反复为所有行查找字段。读取全部通过地址索引匹配定义，纯 WO 地址另建索引，重复状态版本跳过，减少无效遍历与更新。
- 表格以 CSS Grid 定义弹性列与上下排布局，长名称以省略及 title 显示，不撑大整个表。ResizeObserver 在动画帧中合并布局测量，避免回调内同步改写尺寸造成循环通知。宽屏详情高度根据实际面板顶部和工作区底部计算，滚动/缩放/日志面板变化后更新。
- 切换模块重置工作区外层滚动位置，避免连接页的旧滚动位置截去新页标题。上述变化仅涉及界面，不触发连接重建或设备写入。
- 宽屏位域详情面板在工作区内吸顶；根据工作区实际高度（扣除日志和任务栏）限制高度，长内容在面板内滚动。切换寄存器重置详情内部滚动，不改变表格阅读位置。
- 位域详情仅对视图过滤 Reserved，以及名称含 reserved/保留的 RO 字段；普通 RO 仍显示。隐藏与名称相同的重复说明和格式/整字初始值行，保留名称标题、地址、有效说明及非保留字段初始值。原始定义、32 位编辑器和内核保护不改，全部保留时提示“此寄存器仅含保留字段”。
- 日志页删除重复的底部面板开关，底部日志由全局顶部栏控制。“自动跟随”和“导出”分别使用文字标识及说明；暂停跟随时保持阅读位置，重新开启立即定位最新日志，环形列表达到上限后仍按最新日志 ID 跟随。
- 按用户约定，导入图标箭头向下，导出图标箭头向上；寄存器表与日志导出保持一致。自动跟随日志仍用向下箭头，表示定位最新日志。
- 清空日志使用确认弹窗，明确不受筛选范围限制；服务锁内先清数据库再清内存，递增状态版本以同步其他标签。保持数据库日志 ID 单调递增，清空后新日志仍能正确跟随。

## 7. 连接参数与兼容

- SoC：`serial.port` 为 Windows COM 号，统一为大写；保存波特率、数据位、校验位和停止位，校验范围与类型。
- SoC 表单打开或从仪表切回时自动扫描，端口框获焦和刷新按钮可重新枚举；按 COM 自然顺序排序并去重。扫描失败返回明确错误而非伪装成空列表。
- 保留未检测到的已存端口，提示设备可能未插入，不自动选第一个端口；不通过扫描判断端口是否被其他程序占用。
- 波特率采用独立可编辑下拉组件，包含用户指定 15 项预设，默认 115200；支持鼠标选择、上下键/Enter/Escape 及任意范围内整数输入。前后端校验 50～12000000，具体硬件支持能力待驱动接入后判断。
- 仪表：`instrument.ip_address` 保存 IPv4 地址，驱动先按已有项目的 VISA TCPIP 规划；不把 IP 当成串口，也不无依据增加固定 TCP socket 端口。
- 模拟模式允许地址留空，填入 COM/IP 也不访问硬件。硬件配置要求地址完整，且内核拒绝尚未接入驱动的连接请求；UI 不能绕过该检查。
- 参数在已连接时不可编辑，需先断开。编辑、删除和连接共用本设备请求锁，避免相互穿插。
- SQLite 仍保存版本化配置对象，早期新版 `transport=simulation` 的行启动时转换为独立 `mode` 与串口/IP 参数，保留 ID/名称和日志，不填写猜测地址。此兼容仅针对本新版原型，不修改两个参考仓库。

## 8. 文件导入边界

- 仅 `.xlsx` / UTF-8 `.json`，8 MB 文件体、最多 2048 个寄存器、总 20000 行、64 列；Excel ZIP 限制 3000 个成员和 64 MB 解压体积，使用 defusedxml，不解析外部链接，不执行公式或脚本。
- 支持 v1/v2 的 B2 基地址/第 4 行表头以及简单绝对地址表；按 sheet 分组。UI 先读取 sheet 清单再解析所选表，非寄存器表不可选，错误行报错而非静默忽略。
- 工作表清单外固定显示“全选 / 全不选”勾选框及已选/可选数量，全部选中/部分选中/全不选分别显示选中/半选/未选状态；只变更可导入项，解析过程中禁用，未选中任何项时禁止解析。
- 同名“初始值”不能用字典后列覆盖前列：位于“成员变量”之前的为整字 reset，之后的为字段 reset。字段初值校验位宽，导出再导入保留两类初始值。“合并”和“DFT值”按用户要求完全忽略，不验证其内容、不保存、不展示。
- 用户指定原始工作簿以只读方式验证 BLE_System v1（30 项）、BBPLL v2（2 项）、eFuse（14 项）和 PIT（17 项），并完成当前整本 530 项的只读解析。普通测试使用合成样例，额外集成验证通过环境变量 `TESTSTUDIO_REGISTER_WORKBOOK` 指定外部文件，不把原表加入仓库。
- RW/WO/WC/W1C/W1_PULSE/WC_INT 可进入写掩码，RO/Reserved 受保护。用户明确 W1_PULSE/WC_INT 与 WC 等价后，移除先前导入预览的语义待确认警告；已有存档原类型无需改写。v2 通过列结构识别，不引入任何合并逻辑。
- 本轮早期存档或 JSON 若带 `merged` / `dft_value`，在模型入口丢弃；启动时清理已有新版目录中的这两项元数据，其余寄存器定义保持，目录版本更新以刷新界面。
- 地址/初值支持整数或十进制/0x 文本，位域支持 `[msb:lsb]` 和单 bit；未知类型、重复/未对齐地址、重叠/反向/超界字段拒绝。
- 旧 JSON 仅地址和值时可导入，但没有位域的部分自动补 Reserved，需补齐定义后才能编辑；不把历史值声明成真实设备当前值。
