# TestStudio

面向 Windows 本机的芯片调试与射频测试工作台。新版采用独立仓库重构，当前已提供可运行的 **0.1.0 模拟原型**，不访问真实串口或仪表。

当前架构：**Electron + Vue 3/TypeScript + Python 测试内核 + SQLite**。开发时在浏览器中检查同一套界面，也可双击 `start.bat` 打开桌面窗口。无需开发环境的便携发布包尚未制作。

## 现在可以使用

- **连接中心**：SoC 保存串口号、波特率、数据位/校验位/停止位；仪表保存 IP 和 VISA TCPIP 配置。支持新增、断开后编辑、删除，以及模拟连接/断开。通信参数与运行模式分别管理，**硬件配置目前仅保存，真实驱动尚未接入**。配置保存在新版 `data/studio.db`，重启后保持断开；单设备操作只锁本卡片，不影响其他设备。
- **串口参数选择**：打开 SoC 配置时自动扫描系统串口，列表显示 COM 号和设备描述，支持刷新；只枚举、不打开端口。波特率默认 `115200`，可从预设下拉列表选择，也可手动输入其他整数值。未检测到已保存的串口时保留原配置并提示，不自动改选。
- **寄存器工作台**：bit31～bit0、字段提示、整字/单 bit 编辑、全 0/全 1、撤销、单行/全部读取、显式写入及读回校验；支持 **Excel/JSON 导入预览、追加/替换、JSON 导出、单行/勾选批量删除**，定义保存在新版 SQLite，刷新和重启后保留。大表只渲染可见行，滚动、分组和搜索不丢失待写状态。Python 内核保护 RO/保留位，支持模拟 W1C。
- **任务中心**：保留进度、结果及停止的通用框架，供后续采集与测试使用；当前没有面向用户的可启动任务。“后台巡检”仅为模拟回归样例，已按用户要求移除界面入口和使用引导。任务运行时仍锁定手动寄存器操作，任务结束后释放占用但保留连接。
- **日志**：底部或独立标签显示，支持搜索、级别筛选、导出和带确认的 **清空全部日志**；清空会删除内存及数据库中的全部日志，与当前筛选无关，不影响任务，新日志继续记录。
- **界面**：多标签、明暗主题；鼠标移到主导航右边线显示向左箭头，点击收起，收起后移到窗口左边缘显示向右箭头，点击恢复，不再占用顶部按钮。边线控件也支持键盘聚焦和 Enter/空格操作。提高文字对比度和字号，bit 数据不因只读状态而淡化。主题与导航偏好按界面来源保存在浏览器本地。

默认寄存器为自行定义的通用模拟数据，**不对应真实芯片**。导入真实芯片定义也只改变工作台配置，不会访问硬件。IQ、LA、BLE/WiFi、多芯片批量配置与历史测试结果页面尚未实现，导航中明确标注“规划”。

早期新版 `SIM://` 连接配置会自动保留原 ID/名称并转换为串口或 IP 参数结构，不猜测真实地址，也不丢弃原有日志。模拟模式可留空地址；硬件配置必须填写正确的 COM 号或 IPv4 地址，但连接按钮仍明确提示“驱动待接入”。

### 寄存器表导入与删除

在寄存器工具栏点击“导入寄存器表”，选择 `.xlsx` 或 `.json`；Excel 先选择需要的 sheet，再核对预览并确认。列表上方的“全选 / 全不选”只控制可导入工作表，部分选中显示半选状态，同时显示已选数量；非寄存器表始终不可选。默认追加，不覆盖现有地址；地址重复时拒绝追加，只有明确选“替换整个工作台寄存器表”才替换。可先“导出配置”备份，也可下载 [Excel 模板](http://127.0.0.1:5173/api/registers/template)；需开发服务运行并在界面建立本机会话。

- Excel **v1**：B2 为基地址，第 4 行为“名称、说明、偏移地址、初始值、成员变量、位域、类型、初始值、成员描述”；**v2** 增加“合并”和“DFT值”。按表头名称与相对位置识别，整字和字段的两个“初始值”分开读取；**“合并”和“DFT值”按用户要求忽略，不解析、不保存、不展示**。也兼容不含说明/字段初始值列的旧模板，以及简单绝对地址表。
- 多行字段归属前一个寄存器，sheet 作为分组，非寄存器 sheet 在选择框标为不可选。用户指定文件中的 `BLE_System`（v1）30 项和 `BBPLL`（v2）2 项已完成只读解析验证；不代表该工作簿所有其他 sheet 的写语义已支持。
- JSON：支持本软件导出的 `{ "registers": [...] }`，以及参考旧版地址/数据数组；字段可用新版 `fields` 或旧版 `bitfields`/`bit_fields`。
- 32 位寄存器地址需按 4 字节对齐，支持 RW、RO、WO、WC、W1C、W1_PULSE、WC_INT、Reserved，位域不能重叠或超界。没有定义的位自动作为保留只读，不默认可写。
- **WO 为只写**：按完整字段显式提交，允许写 0 和重复命令；无有效读回值，不做读回校验。只有 WO 及保留位的寄存器无需先读取即可编辑，读取按钮禁用，全部读取与巡检跳过；混合寄存器的十六进制读回值以 `?` 表示含 WO 位的四位组，不把上次写入值显示为读回值。
- **WC、W1_PULSE、WC_INT 按用户定义等价，均为写 1 后硬件自动清 0**：保留原类型名称，允许编辑和显式写入。待写值从 0 开始，写 0 不触发；读到 1 也不会自动写回，提交后不做普通值相等校验。模拟驱动用立即清零模拟，不能代表真实硬件动作完成。WO/自清零位写入显示“已提交 · 未校验”，混合写入仅校验已提交的 RW/W1C 位。
- 初始值是寄存器定义值，**不是实际读回值**，不自动下发。忽略的两列不参与任何读写逻辑，其中的内容不影响导入。其他被读取列的 Excel 公式不执行，需先转成值。当前仍拒绝重复地址定义。
- 文件最大 8 MB，最多 2048 个寄存器；无效文件、重复地址、错误位域会明确报错，不部分导入、不改变原表。
- 行末垃圾桶删除单项；左侧复选框勾选后可“删除选中”。全选仅作用于当前筛选结果，删除操作需确认。删除只移除共用定义，不清零、复位或写入芯片，也不重置已有模拟地址值。
- 导入/删除会刷新所有模块共用的定义并清除待写编辑；任务运行时禁止修改表。删空后保持空表，不自动恢复默认项，重新导入即可恢复。
- 用“寄存器表”下拉列表选择全部或某个 sheet/分组，不再使用横向标签。表格只有纵向滚动；完整 bit31～bit0 自动适配当前工作区，宽度不足时名称/数值/操作在上排、32 位在下排，不拆成 16+16。长名称省略显示，悬浮可看完整名称，点击后在详情中查看。
- 位域详情隐藏保留字段、与名称重复的说明，以及格式版本/整字初始值行；普通 RO 字段、有效说明和字段初始值继续显示。仅精简展示，保留字段仍在 32 位视图和导出定义中，写保护不变。

## 开发环境安装

当前验证环境为 Windows、Python 3.13、Node.js 22.20.0。建议 Node.js 22.12+，Python 在本仓库内建立独立虚拟环境，不使用旧项目环境。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
npm.cmd ci
npm.cmd run setup:electron
```

`requirements-lock.txt` 是本次 Windows/Python 3.13 验证环境快照，含测试依赖；`requirements.txt` 和 `requirements-dev.txt` 分别列直接运行和开发依赖。前端依赖由 `package-lock.json` 锁定。

Electron 运行内核需要单独下载一次；如果 GitHub 下载失败，可临时设置镜像，再执行相同安装器，仍使用包内校验和检查：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npm.cmd run setup:electron
```

## 启动

**浏览器开发模式**（前端热更新，Python 不自动重启）：

```powershell
npm.cmd run dev
```

打开 `http://127.0.0.1:5173/`。启动器为 Python 分配空闲本机端口并配置代理，不占用旧版 8081；前端 5173 被占用时明确报错。修改 Python 后需要重启开发命令。

**桌面模式**：安装依赖后双击根目录 `start.bat`，或运行：

```powershell
npm.cmd start
```

该命令先构建前端再启动 Electron，构建耗时不包含在桌面启动指标中。前端已构建时，可用 `npm.cmd run start:desktop` 直接启动。关闭桌面会清理内核，若有运行中任务会先提示。

不要直接用 Python 启动内核代替上述入口：入口负责进程生命周期、会话和端口。日常数据默认为新版 `data/`；可通过 `TESTSTUDIO_DATA_DIR` 指定独立数据目录。模拟数据修改不会触及参考仓库。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
npm.cmd run build
npm.cmd run test:e2e
npm.cmd run test:desktop
```

- 后端测试：共享连接、访问权限、位掩码、W1C、单任务锁、停止、配置保存和 API 会话。
- 浏览器测试：使用本机 Chrome，自动启动独立的 5174 测试入口，数据放在 `data/e2e/`，不干扰开发连接；没有 Chrome 时需修改测试配置并安装 Playwright 对应浏览器。
- 桌面测试：需先构建前端并下载 Electron；验证真实 Electron 窗口、模拟读写入口、安全选项和退出后端口释放。数据放在 `data/desktop-test/`。
- 这些都是软件及模拟验证，不代表真实硬件或便携发布包已验收。

## 核心能力规划

- 连接中心统一管理串口与仪表连接，各模块复用。
- 寄存器整字/bit/位域读写、多芯片配置、对比和同步。
- IQ 采集分析、TXT 或正弦波写入 RAM 回放，后续扩展解调。
- LA 采集、HEX 转 VCD、数字/模拟波形查看及协议解码扩展。
- BLE/WiFi 测试、后台单硬件任务、日志、历史记录及结果对比。
- 浏览器式多标签工作区，日志可在底部或独立标签中展示。
