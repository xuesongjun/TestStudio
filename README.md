# TestStudio

面向 Windows 本机的芯片调试与射频测试工作台。新版采用独立仓库重构，当前仅完成需求与架构草案，尚无可运行应用。

推荐架构：**Electron + Vue 3/TypeScript + Python 测试内核 + SQLite**。日常以便携目录交付，目标为双击打开桌面窗口；开发时可在浏览器中检查同一套界面。技术版本和具体组件将在原型验证后确定。

## 文档入口

- [SPEC.md](SPEC.md)：已确认需求、寄存器交互参考、推荐架构、方案取舍和后续路线。
- [task.md](task.md)：分阶段任务列表、固定任务编号与完成状态。
- [process.md](process.md)：当前断点、进度详情、验证结果和待续事项。
- [AGENTS.md](AGENTS.md)：AI 开发规则、参考仓库只读边界及硬件验证约定。

## 核心能力规划

- 连接中心统一管理串口与仪表连接，各模块复用。
- 寄存器整字/bit/位域读写、多芯片配置、对比和同步。
- IQ 采集分析、TXT 或正弦波写入 RAM 回放，后续扩展解调。
- LA 采集、HEX 转 VCD、数字/模拟波形查看及协议解码扩展。
- BLE/WiFi 测试、后台单硬件任务、日志、历史记录及结果对比。
- 浏览器式多标签工作区，日志可在底部或独立标签中展示。

## 项目边界

本仓库位于 `C:\workspace\TestStudio`，独立于以下只读参考目录：

| 参考目录 | 用途 |
| --- | --- |
| `C:\workspace\test_studio` | 旧版功能、硬件协议、算法和行为参考 |
| `C:\workspace\test_stuio_new` | 寄存器表、bit 编辑、Excel 位域解析与交互参考 |

新版不依赖上述目录的源代码路径、环境、配置或数据库。已有能力将在新版架构内重新实现、验证。
